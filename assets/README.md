# Shortcut artwork

`chatgpt-rtl.png` is the source artwork, generated with OpenAI ImageGen on
9 October 2026. `chatgpt-rtl.ico` contains 16, 24, 32, 48, 64, 128, and 256 pixel
variants converted with Pillow. End users need neither Pillow nor ImageGen.

The icon uses a charcoal tile, white knot, teal left arrow, and RTL label.
Its transparent background is outside the rounded tile. Desktop and Start
menu shortcuts use the ICO in the stable installed controller.

The artwork identifies an independent utility; it is not an official OpenAI
icon or endorsement. Third-party trademarks retain their respective rights.

## Generation prompt

The original prompt is retained for reproducibility:

> Use case: logo-brand. Asset type: Windows desktop shortcut app icon for ChatGPT RTL.
> Create one polished square raster icon inspired by the white interlaced six-loop
> knot of the ChatGPT desktop icon, but clearly differentiated as an independent
> RTL utility. A charcoal rounded square tile with a bold white interwoven knot
> in the upper area, a simple bright teal left-pointing arrow below it indicating
> right-to-left text flow, and the exact short label "RTL" in clean bold white
> sans-serif. Flat crisp shapes, strong contrast, generous margins, readable at
> small Windows shortcut sizes, centered composition. Transparent background
> outside the rounded square tile, genuine alpha. No mockup, no desktop, no extra
> text, no watermark. The arrow must point LEFT. This is the final standalone
> icon asset.
