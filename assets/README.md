# Shortcut artwork

`chatgpt-rtl.png` was generated with the built-in OpenAI ImageGen tool for this
project on 9 October 2026. It is inspired by the ChatGPT desktop knot and adds
a left-pointing arrow and the exact label **RTL** to identify this independent
utility. It is not an official OpenAI app icon or endorsement. OpenAI's marks
retain their respective rights; the code's MIT license does not grant ownership
of third-party trademarks.

The generated RGBA source has genuine transparency outside the rounded tile.
`chatgpt-rtl.ico` contains 16, 24, 32, 48, 64, 128, and 256 pixel variants,
converted from that PNG with Pillow. End users do not need Pillow or ImageGen.
Both Desktop and Start menu shortcuts reference the ICO in the installed
controller's stable assets directory.

## Final generation prompt

Use case: logo-brand. Asset type: Windows desktop shortcut app icon for ChatGPT RTL.
Create one polished square raster icon inspired by the white interlaced six-loop
knot of the ChatGPT desktop icon, but clearly differentiated as an independent
RTL utility. A charcoal rounded square tile with a bold white interwoven knot
in the upper area, a simple bright teal left-pointing arrow below it indicating
right-to-left text flow, and the exact short label "RTL" in clean bold white
sans-serif. Flat crisp shapes, strong contrast, generous margins, readable at
small Windows shortcut sizes, centered composition. Transparent background
outside the rounded square tile, genuine alpha. No mockup, no desktop, no extra
text, no watermark. The arrow must point LEFT. This is the final standalone
icon asset.
